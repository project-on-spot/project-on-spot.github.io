The Manifesto

Project on Spot presents a raw, curated listing of innovative GitHub projects. By design, this platform does not provide project analytics, competition rates, user reviews, or algorithmic recommendations.
We supply the discovery.
The assessment of safety, suitability, and value remains entirely up to you.

Colophon

Project metadata and metrics are not updated dynamically (for now). Star and fork counts reflect snapshots from November 2026.

Submissions
We welcome submissions regardless of star count. Our requirements: your project Open-source, provides genuine value to the technical community.

• Pre-release Projects: If your project does not have an official release yet, please include the "WIP" tag. We are currently developing dedicated features for early-stage work. One link to GH repo or to promo-page

• How to Submit: Open a pull request titled spot—[project-name]. Please note that there is no guaranteed review timeframe.
