Every browser, one API, zero flake tolerance. **Playwright** automates Chromium, Firefox, and WebKit with auto-waiting, network interception, and traces that replay exactly what the page did when it failed.

It turned end-to-end testing from a chore into a discipline — the dress rehearsal every release deserves.

- Cross-browser automation out of the box
- Trace viewer and codegen for authoring tests
- Ships from Microsoft with an Apache-2.0 license
