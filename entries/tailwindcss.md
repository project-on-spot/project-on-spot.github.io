**Tailwind** rejected the costume department in favor of a fabric library: atomic utilities, composed directly in the markup, that make every design decision explicit. Naming things is famously the hard problem — Tailwind simply stopped requiring it.

Purged, minified, and themeable to the token, it has quietly become how the web is dressed.

- Utility classes that mirror CSS at 1:1 scale
- JIT engine generating only what is used
- Design tokens as a first-class API
