Where others ship a runtime, **Svelte** ships a result. The component you write is compiled into minimal vanilla JavaScript — no virtual DOM, no diffing theater — and the reactivity model reads like plain arithmetic.

Svelte 5's runes made the mental model smaller still. The web, tailored rather than layered.

- Compile-time reactivity with runes
- No virtual DOM, no runtime framework
- SvelteKit for full applications
